APLIKASI PERPUSTAKAAN DENGAN UI TKINTER

Struktur program tetap dipertahankan:
1. main.py          : menu utama
2. models.py        : class Buku dan Anggota (PBO)
3. tambah_buku.py   : proses menambah dan menyimpan data buku
4. tampil_buku.py   : membaca dan menampilkan data buku
5. buku.csv         : dibuat otomatis ketika buku pertama disimpan

Cara menjalankan:
1. Pastikan Python 3 sudah terpasang.
2. Simpan semua file dalam satu folder.
3. Jalankan main.py.

Tidak memerlukan instalasi library tambahan karena tkinter, csv, os,
subprocess, dan sys termasuk pustaka standar Python.
